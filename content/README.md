# content/

Audience-growth reels and shorts for @autonomous.buddy (9:16, 30-90 s), published only on social media.
One folder per video: `content/<yyyy-mm-dd>-<slug>/`. Create one with `node backend/scripts/new-project.mjs content <slug> [seconds]` and follow the `content-reel` skill.

| Video | Topic |
|---|---|
| 2026-11-05-nobody-called-them | story reel (first pipeline test) |
| 2026-11-17-astryx-reel | Meta's Astryx open-source repo |
| 2026-11-17-egm-reel | Google's Elephant-Goldfish Model |

Render files are git-ignored; rebuild any video with `npm run render` inside its folder.
